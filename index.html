Acerca de esta demostración

Esta versión funciona completamente en el navegador para permitir una prueba comercial realista. Los cambios son locales y no afectan una base de datos productiva.

Sugerencia para la presentación: crea un pedido nuevo, pásalo a “Listo”, despáchalo y luego márcalo como entregado. Los KPIs y reportes se actualizarán durante el recorrido.
